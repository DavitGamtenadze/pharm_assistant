# Synthetic demo documents

The PDFs in this directory are generated by
`scripts/generate_demo_documents.py`. All people, products, studies, events,
measurements, and procedures are fictional. They contain no PHI and are not
clinical guidance.

Use them to try:

- document upload and deletion
- heading-aware chunking
- page-level retrieval and citations
- multi-document source selection
- the fallback response when a question is not in the sources

Regenerate them with:

```powershell
uv run python scripts/generate_demo_documents.py
```

Do not infer treatment, dosing, safety, or operational instructions from these
files.
